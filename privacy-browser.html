01 — Introduction

Introduction

The Shortest Version

Dhurta Browser collects nothing about you. No personal data, no telemetry, no analytics, no crash reports, no browsing history sent anywhere. Everything stays on your machine. We have no server infrastructure to receive your data because we never built one.

This Privacy Policy governs the data practices of Dhurta Browser, a desktop web browser developed and distributed by Dhurta. We publish this policy because transparency is a prerequisite for trust — and you deserve to know, in complete detail, how software you install on your device handles information about you.

Dhurta Browser is built on the architectural principle of local-first data. Every feature — from browsing history to passwords to privacy tools like Ghost Mode — is implemented without any outbound connection to Dhurta servers. This policy documents that principle in its totality: what we store, where we store it, what we do not collect, and what rights you hold over your own data.

This policy is a living document. If the browser's data handling ever changes materially, this document will be updated with an advance notice period before the change takes effect. You can verify all claims here by auditing the public source code at github.com/prashantkeshr/Dhurta.

05 — Local Storage

Information Stored Locally on Your Device

Dhurta Browser stores data locally to function. All of this data lives exclusively on your device in your user profile directory. No part of it is transmitted to Dhurta or any third party.

What is stored locally

  • Browsing history: URLs, page titles, and visit timestamps stored in a local SQLite database in your profile directory.
  • Bookmarks: Saved bookmarks and folder structure stored as JSON in your profile directory.
  • Saved passwords: Encrypted using the operating system's native credential storage (Windows Credential Manager, macOS Keychain, Linux Secret Service). Raw passwords are never stored in plaintext anywhere.
  • Browser settings and preferences: Your configuration choices stored as JSON.
  • Cookies and site data: Cookies, localStorage, IndexedDB, and service worker caches for websites you visit — scoped per-site and fully deletable by you.
  • Cache: Cached page resources to speed up repeat visits. Fully clearable from Settings.
  • Extension data: Local data stored by extensions you install.
  • Download history: A log of files you have downloaded, stored locally only.
  • Custom themes and interface settings: Any wallpapers, themes, or layout preferences you have configured.
  • Autofill data: Name, address, and payment card data you have saved — encrypted using OS credential storage.

Profile directory locations

Where Your Data Lives

Windows: %APPDATA%\Dhurta\User Data\Default
macOS: ~/Library/Application Support/Dhurta/User Data/Default
Linux: ~/.config/Dhurta/User Data/Default

Open dhurta://transparency in the browser to see every file written, its size, and last modification date.

06 — Ghost Mode & Tor

Ghost Mode & Tor Routing

Ghost Mode is Dhurta's enhanced private browsing feature. When activated, it routes your internet traffic through the Tor anonymity network and applies comprehensive fingerprint spoofing to prevent tracking.

What Ghost Mode does

  • Tor routing: Traffic is routed through at least three volunteer-operated Tor relays before reaching its destination. Websites see only the IP address of the exit node, not your real IP.
  • No local trace: Ghost Mode sessions are entirely in memory. No browsing history, cookies, cache, or session data are written to disk during a Ghost Mode session. When you close a Ghost Mode window, all session data is permanently discarded.
  • Fingerprint spoofing: Canvas fingerprint, WebGL fingerprint, audio fingerprint, font enumeration, hardware concurrency, device memory, screen resolution, and timezone are all spoofed to prevent cross-site tracking.
  • WebRTC disabled: WebRTC is completely disabled during Ghost Mode to prevent IP address leaks through media channels.
  • JavaScript properties spoofed: User agent strings, navigator properties, and other JS-accessible browser attributes are randomised.

What Dhurta knows about your Ghost Mode usage

Nothing. Dhurta does not log which sites you visit through Ghost Mode, when you use it, or for how long. Because Ghost Mode sessions are in-memory only and Dhurta has no server infrastructure to receive logs, there is no mechanism by which Ghost Mode activity could be tracked by Dhurta.

Important — Third-Party Tor Network

The Tor network is operated by independent volunteer relays worldwide — not by Dhurta. While Dhurta cannot see your traffic, Tor exit nodes are outside Dhurta's control. For the highest assurance, verify your protection status using the Omni Dashboard at dhurta://omni before conducting sensitive activity. Tor routing does not make illegal activity legal.

07 — Chakra Shield

Chakra Shield & Built-In Privacy Features

Chakra Shield is Dhurta's integrated privacy protection layer. It is enabled by default and operates entirely locally — there are no cloud lookups, no remote filter updates during browsing sessions, and no data transmitted to Dhurta in connection with its operation.

What Chakra Shield includes

  • Ad blocking: Network-level blocking of requests to known advertising and tracking domains using locally-stored filter lists. No request data is sent off-device during filtering.
  • Anti-fingerprinting: Randomises hardware and browser properties exposed to websites to prevent cross-site tracking without cookies.
  • WebRTC leak protection: Prevents your real IP address from being exposed through WebRTC channels, even when using a VPN.
  • Cookie guard: Blocks third-party tracking cookies and enforces SameSite policies.
  • HTTPS enforcement: Automatically upgrades HTTP connections to HTTPS where available using a locally-stored upgrade list.
Filter List Updates

Filter lists are updated periodically in the background. This update check is a standard HTTPS request to our GitHub releases page containing no user data. The updated list is downloaded and stored locally. No browsing data accompanies any update request.

08 — Cookies & Tracking

Cookies & Tracking Technologies

Cookies set by websites you visit

Like all browsers, Dhurta Browser allows websites to set cookies on your device. These cookies are managed by the browser and are subject to the privacy policies of the websites that set them. Dhurta does not read, intercept, or transmit the contents of cookies set by third-party websites.

Chakra Shield blocks third-party tracking cookies by default. First-party cookies (set by the site you are actively visiting) are allowed unless you specifically block them in Settings.

Dhurta-set cookies

Dhurta Browser itself does not set any cookies on external websites. Dhurta does not operate a cookie-based tracking infrastructure of any kind.

Local browser storage

Dhurta stores browser preferences and profile data in local files and databases as described in Section 05. This is local application data that never leaves your device — it is not cookies in the web tracking sense.

Do Not Track (DNT)

Dhurta Browser supports the Do Not Track (DNT) header and can send it to websites you visit. However, DNT is a voluntary signal — websites are not legally required to honour it. Chakra Shield's active blocking provides stronger, enforced protection than DNT alone.

Global Privacy Control (GPC)

Dhurta Browser supports the Global Privacy Control signal, which notifies websites of your preference not to have your data sold or shared. Under the CCPA, websites operating in California are legally required to honour this signal.

09 — Third-Party Websites

Third-Party Services & Websites You Visit

Dhurta Browser is a tool that connects you to the web. When you visit websites, those websites may collect data about you subject to their own privacy policies. Dhurta has no visibility into, and no responsibility for, what third-party websites collect from you.

What Dhurta does not embed

  • Advertising networks or ad SDKs of any kind
  • Google Analytics, Mixpanel, Amplitude, Segment, or any analytics SDK
  • Sentry, Bugsnag, Crashlytics, or any crash reporting service
  • Facebook Pixel, Google Tag Manager, or any marketing tracking pixel
  • Social login buttons (Google Sign-In, Facebook Login, etc.)
  • Cloud sync services that transmit your browsing data to any server
  • Data broker integrations or audience targeting SDKs
  • Any third-party SDK that makes outbound network calls without your explicit instruction

Your chosen search engine

When you type a query in the address bar, Dhurta sends that query to whichever search engine you have configured (default: DuckDuckGo). That query is subject to your chosen search engine's own privacy policy. Dhurta does not intercept, log, or receive a copy of your search queries.

Extensions

Third-party extensions you install from the Chrome Web Store or other sources are independent software. Dhurta cannot control or take responsibility for the data practices of extension developers. Review each extension's permissions and privacy policy before installing it.

10 — Software Updates

Software Updates

Dhurta Browser periodically checks for new versions. This check is performed by making a standard HTTPS GET request to our public GitHub Releases page. The request:

  • Contains no user identifier, device identifier, session token, or personal data of any kind
  • Is a plain HTTPS GET to a public GitHub URL — identical to any browser request
  • Is subject to GitHub's own privacy policy for public repository traffic, not Dhurta's
  • Contains only the standard HTTPS headers sent by any browser request

You can disable automatic update checks entirely in Settings → General → Updates. If you install Dhurta through the Microsoft Store, updates are managed by the Store and are subject to Microsoft's own update infrastructure.

Version Check Endpoint

The update check URL is: https://github.com/prashantkeshr/Dhurta/releases/latest. You can verify this in the source code. No proprietary update server is involved.

11 — Security

Security Measures

Dhurta applies the following security practices to protect data stored locally on your device:

  • OS-level credential encryption: Saved passwords and sensitive autofill data are encrypted using Windows DPAPI, macOS Keychain, or Linux Secret Service — the strongest encryption available on your operating system.
  • SQLite encryption for sensitive databases: Profile databases containing sensitive session data are encrypted at rest.
  • Sandboxed process model: Browser tabs run in isolated renderer processes following Chromium's multi-process security architecture, limiting the blast radius of any compromised tab.
  • No plaintext credential storage: At no point are raw passwords or payment card numbers written to unencrypted files on disk.
  • HTTPS enforcement: Chakra Shield upgrades connections to HTTPS wherever possible, protecting your data in transit to websites you visit.
  • Regular security updates: Security patches are released promptly as part of the normal update cycle.
Security Disclosure

Dhurta's security measures protect data at rest on your device. They do not protect against physical access to an unlocked device, malware running with your user permissions, or vulnerabilities in the websites you visit. If you discover a security vulnerability in Dhurta Browser, please report it to security@dhurta.org. We treat all security reports as high-priority and respond within 24 hours.

12 — Children's Privacy

Children's Privacy

Dhurta Browser is a general-purpose web browser intended for users of all ages. Because we collect no personal data from anyone, we comply with the Children's Online Privacy Protection Act (COPPA) and comparable international regulations by default — there is no data collection to restrict.

Dhurta does not knowingly collect personal information from children under the age of 13 in the United States, under the age of 16 in the European Union, or under the minimum age defined by applicable law in other jurisdictions. Because we collect no personal data at all, this standard is met categorically.

Parents and guardians are encouraged to supervise their children's internet usage. We recommend parental control software for households with minor children.

If you believe a child under the applicable minimum age has transmitted personal data to us (for example, via a support email), please contact us immediately at coppa@dhurta.org and we will take prompt steps to delete that information.

13 — GDPR Rights

Your Privacy Rights (GDPR — EU / EEA / UK Users)

If you are located in the European Economic Area, the United Kingdom, or Switzerland, the General Data Protection Regulation (GDPR) grants you the following rights. Because Dhurta Browser processes no personal data on our servers, these rights are exercisable primarily over locally-stored data, which is entirely under your own control.

👁️
Right of Access (Art. 15)
Request a copy of any personal data we hold. Because we hold none on our servers, local data can be found at dhurta://transparency.
✏️
Right to Rectification (Art. 16)
Request correction of inaccurate data. Local browser data can be edited directly from browser settings at any time.
🗑️
Right to Erasure (Art. 17)
Request deletion of your personal data. Local data is cleared from Settings → Privacy → Clear Data. Uninstalling + deleting the profile directory removes everything.
📦
Right to Portability (Art. 20)
Export your data in machine-readable format. Use File → Export Bookmarks or History to export local data at any time.
🚫
Right to Object (Art. 21)
Object to processing of your data. Because we process nothing on our servers, there is nothing to object to on our end.
⏸️
Right to Restrict (Art. 18)
Restrict processing. Local processing can be restricted by modifying settings or using Ghost Mode for session isolation.

To exercise any of these rights or to file a complaint about our data practices, contact our Privacy team at privacy@dhurta.org. You also have the right to lodge a complaint with your national Data Protection Authority (DPA).

Legal Basis for Processing

To the extent that any processing of personal data occurs (such as processing local browser data to provide browser functionality), the legal basis is performance of a contract — the browser cannot function without storing some data locally on your device — and legitimate interest in providing the service you have installed. We do not process personal data for marketing, profiling, or automated decision-making.

14 — CCPA Rights

Your Privacy Rights (CCPA — California Users)

If you are a California resident, the California Consumer Privacy Act (CCPA) and the California Privacy Rights Act (CPRA) grant you the following rights:

  • Right to Know: You have the right to know what personal information we collect, use, disclose, and sell. See Section 04 for the complete list of data we do not collect. We collect no personal data on our servers.
  • Right to Delete: You have the right to request deletion of personal information. Because we hold no personal information on our servers, deletion requests apply to locally-stored data, which you can clear at any time from Settings → Privacy → Clear Browsing Data.
  • Right to Opt Out of Sale: Dhurta does not sell, rent, lease, or trade personal information. There is nothing to opt out of.
  • Right to Non-Discrimination: Dhurta will not discriminate against you for exercising any of your CCPA rights.
  • Right to Correct: You have the right to request correction of inaccurate personal information. Local browser data can be managed directly from the browser interface.
  • Right to Limit Use of Sensitive Personal Information: We do not collect or process sensitive personal information as defined under the CPRA.

To submit a CCPA request, contact us at privacy@dhurta.org with the subject line "CCPA Request."

Do Not Sell or Share

Dhurta does not sell, share, rent, or otherwise disclose personal information to third parties for any purpose. We have no advertising partners, no data brokers, and no revenue model based on user data. This is not a policy position that requires opting out — it is the default and permanent state of the product.

15 — Universal Rights

Universal Rights for All Users

Regardless of your location or the specific laws applicable to you, every Dhurta Browser user has the following rights over their data:

  • Full transparency: Open dhurta://transparency at any time to see every file the browser has written to your disk, its size, and when it was last modified.
  • Immediate data deletion: Clear all browsing data at any time from Settings → Privacy → Clear Browsing Data. No waiting period, no support ticket, no approval required.
  • Data portability: Export your bookmarks, history, and settings as standard JSON files that can be read by any text editor or imported into another browser.
  • Profile portability: Your profile directory is a standard filesystem folder. Copy it, back it up, move it to another machine, or archive it freely.
  • Complete erasure: Uninstalling Dhurta Browser removes the application. Deleting your profile directory removes all data the browser has ever stored. No residual server-side data exists.
  • No dark patterns: We will not use confusing interfaces, pre-ticked boxes, or psychological manipulation to discourage you from exercising your privacy rights.

17 — International Users

International Users & Data Transfers

Dhurta Browser is available worldwide. Because the browser stores all data locally on your device and does not transmit personal data to any server, there are no international data transfers to disclose under GDPR Article 46 or comparable frameworks.

The only outbound connections to Dhurta-related infrastructure are version-check requests to GitHub (a public endpoint containing no personal data). GitHub operates under its own privacy policy and security certifications.

Users in the EU, UK, Switzerland, Canada, Australia, Brazil, Japan, South Korea, and all other jurisdictions with specific data protection laws are subject to the same zero-data-collection architecture as all other users. No special terms apply — the product simply does not collect the data that such laws would otherwise regulate.

18 — Policy Changes

Changes to This Privacy Policy

Dhurta may update this Privacy Policy from time to time. The nature of any change will determine how we communicate it:

  • Material changes (changes that increase data collection, change the purpose of data use, or affect your rights) will be announced with at least 30 days' notice via a notice in the browser itself and an update to this page.
  • Non-material changes (clarifications, corrections, adding detail without changing practice) will be published with an updated date on this page.
  • All historical versions of this policy remain accessible in the GitHub repository's commit history.

Because our core data commitment — zero telemetry, local storage only — is an architectural property of the software rather than just a policy, any change to it would require releasing new source code visible in the public repository before it reached users through an update.

Verification

You can verify that the browser's data practices match this policy at any time by reviewing the source code at github.com/prashantkeshr/Dhurta. No amount of policy text changes what code actually does. We encourage users to treat the source code as the authoritative record.
