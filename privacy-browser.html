01 — Overview

The Short Version

Dhurta collects nothing about you. No usage analytics, no crash reports, no browsing history sent anywhere, no account, no email, no identifiers of any kind transmitted to any server. Everything the browser stores lives on your device and is fully readable by you.

This is not a marketing claim — it is an architectural constraint. Dhurta has no server infrastructure to receive telemetry, because we never built one. The source code is public on GitHub and can be audited to verify every statement in this policy.

03 — Local Data

Data Stored Locally on Your Device

Dhurta Browser stores the following data locally to provide browser functionality. All of it is stored in readable, standard formats on your device and is never transmitted anywhere:

  • Browsing history (SQLite database in your user profile directory)
  • Bookmarks (JSON file in your user profile directory)
  • Browser settings and preferences (JSON)
  • Saved passwords, encrypted using OS-level credential storage
  • Cookies and site data, scoped per-site (deletable at any time)
  • Cached web content to speed up page loads (clearable at any time)
  • Extension settings and local extension data
  • Download history log
  • Custom themes and wallpapers you have applied

You own all of it. The Transparency Dashboard (accessible at dhurta://transparency) shows the exact location of every file the browser has written to your disk. You can export, delete, or inspect any of it at any time.

04 — Ghost Mode & Tor

Ghost Mode & Tor Routing

When Ghost Mode is enabled, Dhurta launches a bundled Tor binary that routes your traffic through the Tor network. The following applies:

  • Your real IP address is hidden from websites you visit — they see a Tor exit node instead.
  • Dhurta does not log which sites you visit through Tor.
  • The Ghost Mode session is in-memory only — no history, cookies, or cache are written to disk when Ghost Mode is active.
  • Your browser fingerprint is spoofed during Ghost Mode sessions.
  • WebRTC is fully disabled during Ghost Mode to prevent IP leaks.

Important: While Dhurta routes your traffic through Tor and collects nothing itself, the Tor network is operated by independent volunteer relays. Dhurta has no control over exit nodes. For sensitive use cases, always verify your protection status using the Omni Dashboard (dhurta://omni).

05 — Third Parties

Third-Party Services & Websites

Dhurta Browser is a tool that connects you to the web. When you browse websites, those websites may collect data about you subject to their own privacy policies. Dhurta has no control over and no visibility into what third-party websites collect.

Dhurta Browser does not include or embed any of the following:

  • Advertising SDKs or ad networks
  • Analytics SDKs (Google Analytics, Mixpanel, Amplitude, etc.)
  • Crash reporting services (Sentry, Bugsnag, Crashlytics, etc.)
  • Social login or identity providers
  • Cloud sync services that transmit your data
  • Any third-party data broker integrations

The only outbound network connections Dhurta makes on its own (not on your instruction) are: checking for software update version numbers from GitHub Releases. This check contains no user identifiers and can be verified in the source code.

06 — Software Updates

Software Updates

Dhurta Browser periodically checks for new versions by making a version-check request to GitHub Releases. This request:

  • Contains no user identifier, device identifier, or any personal data
  • Is a standard HTTPS GET request to a public GitHub URL
  • Is subject to GitHub's own privacy policy for public repository traffic
  • Can be disabled in browser settings

Update packages are downloaded from GitHub Releases or the Microsoft Store depending on how you installed the browser. Dhurta does not operate its own update servers.

07 — Children's Privacy

Children's Privacy

Dhurta Browser does not collect any personal information from anyone — including children. Because we collect nothing, there is no specific age restriction from a data-collection standpoint. However, parents and guardians are responsible for supervising their children's internet use. We recommend using parental control software for households with minor children.

08 — Your Rights

Your Rights & Control

Because all data is stored locally on your device and nothing is transmitted to Dhurta, you have complete and immediate control over all your data at all times:

  • Access: Open dhurta://transparency to see every file the browser has written.
  • Delete: Clear your history, cookies, cache, and all browser data from Settings → Privacy.
  • Export: Export bookmarks, history, and settings as standard JSON files at any time.
  • Portability: Your profile is a standard directory on your filesystem — copy, move, or back it up freely.
  • Erasure: Uninstalling Dhurta Browser removes the application. Deleting your profile directory removes all locally stored data.

There is no account to delete, no server-side data to request, and no data deletion form to submit — because nothing was ever sent to us.

09 — Changes

Changes to This Policy

If we update this privacy policy, the new version will be published at this URL with an updated effective date. We will not send you a notification — there is no account or email address to send it to. We encourage you to review this page when updating the browser.

The core commitment — zero telemetry, zero data collection, local storage only — is an architectural property of the software, not a policy that can be changed without publishing new source code. Any such change would be visible in the public GitHub repository.
